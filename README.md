# 🎵 WaveOn

**WaveOn** é uma aplicação web de descoberta musical desenvolvida com Laravel, que integra APIs externas para obter e apresentar conteúdos musicais num único lugar.

## 🚀 Funcionalidades

- 🎵 **Músicas:** Explorar faixas musicais disponibilizadas por uma API externa.
- 🎼 **Categorias Musicais:** Explorar categorias musicais e os respetivos conteúdos.
- 🔎 **Pesquisa de Músicas:** Pesquisar faixas através da funcionalidade de pesquisa da API.
- 📄 **Detalhes das Músicas:** Consultar as informações disponíveis sobre as faixas musicais.
- 🔗 **Integração com APIs:** Obter e apresentar dados provenientes de uma API musical externa.

## 🛠️ Tecnologias

- PHP
- Laravel
- Blade
- Tailwind CSS
- Integração com APIs REST

## 🎯 Objetivo

O WaveOn foi desenvolvido como um projeto prático para aprimorar os meus conhecimentos em desenvolvimento com Laravel, consumo de APIs, organização de serviços e criação de aplicações web dinâmicas.
